# Task 3 - CSS Units, Box Model, and Fonts

## Overview

This project demonstrates the use of HTML and CSS concepts including viewport units, the CSS box model, gradients, and font styling. The webpage displays an image with a button placed directly below it.

## Features

- Responsive layout using viewport (`vw` and `vh`) units.
- Image centered horizontally on the page.
- Equal spacing from the left and right sides of the viewport.
- Top and bottom spacing using viewport height.
- Gradient background button.
- Custom font styling for the button.
- Uses the CSS Box Model (`box-sizing: border-box`).
- No Flexbox, positioning, or `overflow: hidden` used.
